# M2 八阶段受控数据采集

| 属性 | 值 |
|---|---|
| 状态 | approved |
| Owner | Domain + Web + QA |
| 时间盒 | 2 天目标 |
| PRD 追踪 | 3.3、4.1、4.2、5.2、7 |

## 目标

工程师只能通过八阶段问答把可计算、可追溯且通过强校验的数据写入项目，刷新可恢复，并发修改不会互相覆盖。

## 范围

包含：字段 registry、双语对话配置、结构化确认卡、8 阶段状态机、建筑/楼层/区域、唯一工序绑定、主要工序覆盖、工艺环境、冷量输入、PCW 直输、计划/蓄冷、阻断/警告、影响分析、revision 和结果失效。

不包含：自由表单入口、Excel 导入、2D 画布、任意流程 DSL、设备级 PCW 推导。

## Definition of Ready

- [ ] M1 verified。
- [ ] 字段 registry 与 HDI 对话 seed 为 SOFTWARE_VERIFIED。
- [ ] 八阶段状态、Answer Command、revision/impact token 契约 approved。
- [ ] 规则来源和未核验警告策略 approved。

## 八阶段门禁

1. 项目/模板：已发布模板；首个建筑后产品锁定。
2. 地理/气象：坐标/时区/静态工况来源有效。
3. 建筑/楼层：至少一栋一层，正面积/层高，上限 10×10。
4. 区域/工序：≤300 区域，唯一绑定，主要工序全覆盖；面积 0–3% 警告需原因，>3% 阻断。
5. 工艺环境：已核验硬规则阻断，经验超限警告放行需原因。
6. 冷量输入：SI 结构化确认；PCW 明确值或 0。
7. 计划/蓄冷：主要工序计划无重叠；蓄冷只保存不计算。
8. 复核：阻断为 0、警告确认，冻结 revision。

## 测试矩阵

| 层级 | 必测行为 |
|---|---|
| Unit/Property | 字段类型/单位/范围、状态转换、面积容差、工序覆盖 |
| Contract | impact/confirm、message key、409/422、幂等提交 |
| Integration | Answer Command 原子写入、审计、revision、失效传播 |
| E2E | 8 阶段、刷新恢复、修改已完成字段、双 Tab 冲突 |
| i18n | 所有问题/选项/错误有 zh-CN/en-US，缺 key 测试失败 |

## 演示脚本

创建 HDI 项目，故意遗漏填孔电镀区域被阻断；补齐后输入 4% 面积超限被阻断，改为 2% 并填写原因后放行；刷新恢复到首个未完成问题；双 Tab 用旧 revision 确认时得到 409 且无部分写入。

## 质量门禁与 Definition of Done

- [ ] 自然语言只生成待确认卡，不直接写业务表。
- [ ] 字段类型/单位/主阶段/强校验不可由管理员修改。
- [ ] 结果失效按 static/historical/forecast 分域表达。
- [ ] 300 区域边界和所有失败恢复测试通过。
- [ ] M2 Acceptance Record 为 GO。

## 停止条件

若出现绕过问答写入、自然语言直接持久化、并发覆盖、主要工序漏检或结果未失效，阻断 M3。
