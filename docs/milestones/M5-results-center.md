## 目标

工程师可在桌面 Web 通过五个 Tab、统一筛选和区域下钻快速理解工厂静态与逐时冷量；界面中英文和明暗主题保持同一数据口径。

## 范围

包含：静态/历史/预测/质量/导出入口五 Tabs、统一 URL 筛选、KPI、曲线、排名、负荷持续时间、区域详情、区域/工艺/楼层/建筑/工厂五维查询、中英文/明暗主题。

不包含：CSV 文件生成与下载、部署收口、地图、2D Canvas、移动端、Excel/PDF/JSON 报告、冷站/前馈灰色入口。

## Definition of Ready

- [ ] M4 verified，存在有效静态/历史/预测批次。
- [ ] Analytics API、筛选和分页契约 approved。
- [ ] UI design token、i18n key、五页面四主题基线 approved。
- [ ] Web Feature Specs 和测试计划 approved。

## 展示不变量

- 工艺与空间是并列筛选/聚合维度。
- Tab 切换保持筛选并同步 URL。
- 图表、KPI、表格和区域详情复用 analytics 查询口径。
- 失效结果显示全局横幅，不伪装为当前有效结果。
- 从结果首页以“打开筛选 → 选择区域 → 打开详情”三次交互看到静态分项和逐时曲线。
- 用户自定义名称保持原文；系统文案、错误、内置模板和图表支持 zh-CN/en-US。

## 测试矩阵

| 层级 | 必测行为 |
|---|---|
| Contract | analytics 五维筛选、分页、lineage、空值和错误 |
| Integration | KPI/图表/表格使用同一查询，筛选 URL 可恢复 |
| E2E | 五 Tabs、五维筛选、三次交互区域定位、失效横幅 |
| Visual | 登录、项目、问答、结果、模板 × 2 locale × 2 theme，1440×900 |
| Accessibility | 键盘主路径、焦点、错误关联、正文对比度达到 WCAG AA |

## 演示脚本

从结果首页按工艺查看 LDI，再按楼层/建筑/工厂对比；切换静态、历史、预测 Tab 后筛选保持；三次交互打开 LDI 东区，查看六分项、三类冷源和逐时曲线；切换中英/明暗无缺 key、遮挡或阻断错位。

## 质量门禁与 Definition of Done

- [ ] P0_10、P0_11 和 P0_12 的 UI 部分均有测试追踪。
- [ ] 同一筛选下 API、KPI、图表和表格数值一致。
- [ ] 五维查询和区域下钻权限正确。
- [ ] 四主题截图通过，英文长文本不遮挡主操作。
- [ ] M5 Acceptance Record 为 GO。

## 停止条件

任一越权、聚合口径不一致、筛选跨 Tab 丢失、区域无法下钻、缺失资源键或失效结果无标识均阻断 M6。
