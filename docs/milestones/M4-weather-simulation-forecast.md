# M4 气象、历史仿真与未来预测

| 属性 | 值 |
|---|---|
| 状态 | approved |
| Owner | Data + Calculation + API + QA |
| 时间盒 | 1 天目标 |
| PRD 追踪 | P0_07、P0_09；3.4、3.6、6.4、10 |

## 目标

用有效静态批次、逐时气象、工序计划和版本化经验系数生成三年历史仿真与连续 168 小时预测，并保证任务和时间轴正确。

## 范围

包含：真实气象 Provider、标准 CSV 兜底、`LOCATE / REQUEST / DOWNLOAD / CLEAN / VALIDATE / STORE` 六阶段进度、UTC 时间轴、天气矩阵双线性插值、生产率线性插值、区域宽表、五维聚合、每小时预测刷新、current/归档/过期。

不包含：精度承诺、真实生产数据校准、前馈控制、水蓄冷计算。

## Definition of Ready

- [ ] M3 verified。
- [ ] 气象 CSV、任务、时间轴和系数契约 approved。
- [ ] 24 小时动态、三年历史、168 小时预测及无效反例 fixture 可用。
- [ ] 异步任务和 MySQL 批量写入 ADR approved。

## 公式与时间不变量

- CHW_LOW/MEDIUM：静态分项 × 对应天气系数 × 工序生产系数。
- PCW：静态 PCW × 1 × 工序生产系数。
- 天气矩阵内部缺点阻断，轴外钳制并警告。
- 生产系数分段间线性插值；无计划 productionRate=0；例外日优先。
- UTC 整点为唯一键；DST 重复本地小时分别计算，跳失小时不补。
- 旧依赖指纹任务不得覆盖新 current。
- 城市等地理字段变化必须递增 input revision，使旧气象任务失效或取消并创建新任务；旧任务晚完成时仍不得发布或覆盖新 revision 的 current。

## 停止条件

时间轴不唯一、缺小时自动静默填充、PCW 乘天气、旧任务覆盖或任务失败仍产生有效结果均阻断 M5。
