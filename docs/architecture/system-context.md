  | 账号、模板、规则、对话、系数
  v

## 外部参与者

| 参与者 | 交互 | 权限边界 |
|---|---|---|
| 管理员 | 创建工程师；维护并发布模板/规则/配置/系数；转交项目 | 可见全部项目和后台配置 |
| 工程师 | 创建并维护自己的项目；计算、仿真、查看和导出 | 只能访问自己拥有的项目 |
| PCB/暖通专家 | 提供黄金样例和签认 | 0.6 不建立第三系统角色 |
| 气象 Provider | 提供历史和预测逐时天气 | 经 Provider 接口隔离，不信任外部数据质量 |
| GitHub/CI | 管理代码、审查和质量门禁 | 不保存产品运行数据 |

## 关键系统不变量

- 一项目等于一工厂且只生产一种 PCB 产品。
- 功能区只绑定一道工序，主要工序必须覆盖。
- 模板、规则、对话和系数以不可变快照进入项目。
- 所有计算绑定输入 revision 和依赖版本。
- 工艺与空间是两条并列聚合路径。
- UI 与 CSV 复用同一查询口径。
- 0.6 动态结果是经验模型，不承诺预测精度。
