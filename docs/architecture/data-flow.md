# PCB-CDSO v0.6 数据流

| 属性 | 值 |
|---|---|
| 状态 | approved |
| 版本 | 0.1.0 |

## 主数据流

```text
发布配置快照
  -> 新建项目
    -> 八阶段受控答案
      -> Answer Command + revision
        -> 项目业务表 + 审计
          -> 冻结输入快照
            -> 静态区域结果
              -> 工艺/楼层/建筑/工厂聚合
                -> 天气 + 工序计划 + 经验系数
                  -> 区域逐时结果
                    -> 五维查询
                      -> Web 图表 / CSV
```

## 写入规则

| 写入 | 原子边界 | 失败行为 |
|---|---|---|
| 确认答案 | `expectedInputRevision` 校验、答案、审计、revision 递增 | 409 或 422，不部分写入 |
| 发布模板 | 工序/规则/对话/系数引用整套冻结 | 任一引用无效则不发布 |
| 静态批次 | 输入和依赖指纹、区域中间值、聚合 | 整批失败，不生成 current |
| 动态批次 | staging 宽表、聚合、依赖指纹 | 旧任务可留日志但不切 current |
| CSV | 基于有效批次和统一 analytics 查询 | 失效时终止并禁止下载 |

## 失效传播

```text
关键输入变化
  -> inputRevision + 1
  -> 静态 STALE
  -> 历史 STALE
  -> 预测 STALE/EXPIRED
  -> 现有导出不可作为有效结果
```

配置新版本不会污染既有项目；只有新项目或显式的新模板快照使用新配置。
